Build a plugin for Moodle that is a Hackathon style assignment. This can be a group assignment or an individual assignment. It can have a rubric or grading guide associated with it as an advanced grading method. Student must submit a slide presentation either attached or a link. Optional submission additions are a demo video (upload or link), a demo site (link), and code repo (link). Instructors can decide what is mandatory for submission and what is optional when setting up the assignment. This assignment type must be compatible with Moodle versions 4.5.x up through Moodle 5.3.x.
