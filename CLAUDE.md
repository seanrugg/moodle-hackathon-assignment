# Moodle Hackathon Assignment Plugin

## Project Overview
A Moodle activity plugin (`mod_hackathon`) that provides a Hackathon-style assignment.

## Requirements
- **Compatibility:** Moodle 4.5.x through 5.3.x.
- **Assignment Types:** Supports both individual and group assignments.
- **Grading:** Supports rubrics and grading guides.
- **Submission Requirements:**
    - Slide Presentation (Mandatory: File upload or Link).
    - Demo Video (Optional: File upload or Link).
    - Demo Site (Optional: Link).
    - Code Repository (Optional: Link).
- **Configuration:** Instructors can toggle which of the optional fields are mandatory during setup.
- **Implementation:** Standard Moodle activity module structure.

## Development Standards
- Follow Moodle coding standards.
- Ensure compatibility across the specified versions.
- Use secure database queries and input validation.
